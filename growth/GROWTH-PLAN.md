## Lever 2 — Reels (the discovery engine)
- Format: 1080×1920 vertical, panel-by-panel reveal of an existing strip, slow zoom,
  hook text in the first 2 seconds, payoff panel last, loop-friendly ending.
- Cadence: 2–3 reels/week, built from the strongest posts first
  (playbook → own answers → hair strands), then new strips day-and-date.
- Reel #1: playbook post (Oct 12, 23♥) — in production 2026-10-24.
- Every reel caption: hook line + question + hashtag set (below). End card text:
  "Full strip on the profile — start at post 1."

## Lever 3 — Caption system (comments + saves + shares)
Every caption follows: HOOK (1 line, the relatable pain) → 1–2 line beat →
QUESTION or SEND-TO prompt → hashtags.
- Question prompts rotate: "What advice did YOUR parents give you?" /
  "Who's winning this argument in your house?" / "Toronto or SF — pick one." /
  "What would your list say?"
- Send-to prompts on couple strips: "Send this to the one who never eats lunch on time."
- Save prompt on list/advice strips: "Save this for the next family video call."
